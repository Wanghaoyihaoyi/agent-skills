# 移动端设计系统

适用于 iOS、Android、手机网页和小程序。先确认实际系统、窗口容器、导航方式、逻辑单位和输入设备。用平台组件承担系统手势、导航和键盘行为。

## 视口、触控与导航

- iOS 触控目标默认至少 `44 × 44 pt`，Android 至少 `48 × 48 dp`。小图标扩展命中容器，相邻热区不重叠。高频主动作置于易触达范围。跨系统手机网页可用 `48 × 48 CSS px` 作为项目无约定时的起点。
- 使用实际安全区和可用高度。原生与 Flutter 使用系统 inset 或组件布局，适配刘海、手势条、横屏和文字放大。全屏 H5 启用 `viewport-fit=cover`，在负责避让的容器应用 `env(safe-area-inset-*)`。底栏保留基础内边距和实际底部 inset，滚动内容为固定操作区留出空间。检查嵌套容器有没有重复避让，保留页面缩放。
- 常驻底部栏适合少量一级目的地，常见 3–5 项。有短标签和清楚的当前状态。分段控件用于单模块内少量视图，详情走导航栈，临时支线走浮层。详情出现专用底栏或需要沉浸时，按导航结构决定是否隐藏全局 TabBar。
- iOS 保护边缘返回，Android 保留系统返回及运行时支持的预测返回。横滑列表、轮播、拖拽与系统边缘动作冲突时，限定手势识别范围。滑动、长按可作为捷径，关键动作保留显式、可访问的入口。

## 表单与软键盘

- 常用字段就近呈现，长表单按任务分组，存在前后依赖再分步。使用真实标签，示例格式放占位或辅助提示，字段错误就近说明。
- 按字段选原生键盘。Web 手机号使用 `type="tel"` / `inputmode="tel"`，验证码使用文本字段、`inputmode="numeric"` 和 `autocomplete="one-time-code"`，金额支持 `decimal`，邮箱使用 `email`，搜索和下一项使用对应提交键。保留粘贴、自动填充及前导零。键盘类型不替代校验。
- 键盘出现后保证焦点、错误提示和当前操作可见。优先用系统 inset、原生滚动容器或可见视口变化修正遮挡，必要时只滚动当前字段到可见区域。避免对每次聚焦固定延时滚动或写死键盘高度。按平台支持“下一项”“完成”或拖动收起，并验证收起后的视口恢复。

## 浮层与滚动

| 需求 | 形态 |
| --- | --- |
| 从少量同类动作中选择 | Action Sheet，取消项与业务动作分开 |
| 临时筛选、选择或评论 | Bottom Sheet，按内容选择约 30%、60%、80% 的初始档，受可用视口、安全区和键盘约束。支持拖动才展示手柄 |
| 破坏性确认或短阻断 | 平台对话框，说明对象与影响，提供明确取消 |
| 长表单、多步操作或独立详情 | 独立页面，避免多层浮层叠加 |
| 低风险状态反馈 | 短提示。确有撤销操作时用平台可交互 Snackbar，保留足够操作时间 |

模态浮层打开后只让内部滚动，背景滚动位置在关闭后恢复。列表未到顶部时优先消化内部滚动，到顶部再判断向下拖动是否为关闭。含录入的浮层禁止遮罩误关，手势和返回也要保护未保存输入。退出过渡完成前保持背景不可交互，防止同一次触摸触发底层操作。

## 信息流与验收

- 手机列表以摘要、状态和主要动作组织，细节下钻。需要精确比较时保留关键列和可访问的局部横滚，避免把完整桌面表格压小。图片预留尺寸，优先保住主体。内容规模影响帧率时再选虚拟化。
- 区分首次加载、刷新、加载更多、已到底、弱网和失败。追加失败保留已加载条目，返回恢复滚动与上下文。吸底主操作不盖住列表末项。顶部或底部指示能从内容里清楚辨认。
- 涉及系统手势、键盘、软硬安全区或浮层时，在相关 iOS／Android 真机或目标容器分别检查。覆盖横竖屏和文字放大中实际支持的模式，试边缘返回、输入和收起、浮层打开与关闭、内部滚动与快速点击。手机网页的浏览器差异可结合 `mobile-native` 核对。
