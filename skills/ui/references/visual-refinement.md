# 视觉层级与细节调节

用于现有界面视觉打磨或参考图改造；按实际问题选用，不强制全页重做。先遵循用户参考和项目设计体系。目标是让重要内容、状态和操作更容易被发现，不把深色、低饱和、极简或去掉品牌特色当作通用目标。

方法参考 [Damir Sokolovsky 的 unslop](https://github.com/heydamir/unslop)（CC BY 4.0），结合本技能的跨平台和任务导向约束调整。

## 诊断与改动范围

先看真实渲染和内容，记录问题的位置、现象及对理解或操作的影响。区分系统性问题与局部瑕疵：前者可在授权范围内统一调整，后者只修受影响处并延续现有方向；没有明显问题就直说，不为制造变化而改版。仅有截图或线上链接而没有源码时，说明依据和交付边界；静态复刻不能证明原页面的交互、动画或真实数据。

明确改版时，从产品和使用场景提炼方向：使用者要完成什么，界面应传达什么具体性格，哪些真实内容值得成为视觉重点，以及是否有适合品牌的细节可以贯穿。保留已建立的品牌与用户认可的表达；不为了增加特色凭空创造功能、宣传数据或装饰。让重要内容有表现力，必要时用色彩、材质、图像或动效强化重点，周围元素为它提供清晰层级，而不是要求每屏都套同一种构图。

复杂打磨可按问题分轮处理：先调整结构与间距，再看色彩、图标、文案、排版、细节和视觉素材，最后检查动效；顺序按依赖关系调整，不必机械跑完每一轮。完成后对照原问题复看实际渲染，并检查改动是否引入新的状态或可用性问题。

## 先找出竞争注意力的元素

用真实内容和实际尺寸观察页面：标题、关键数据、当前导航和主要操作的注意力顺序是否符合任务；是否有多处大面积强调色、粗体、徽章、发光或图标同时争抢注意力。区分装饰与承载功能的提示，保留重要操作、状态和品牌识别。可先临时降低装饰强度，检查没有颜色时布局和文字层级是否仍清楚，再按语义恢复强调。

## 对齐与间距

- 检查导航图标列、文字列、内容区标题、卡片内容和图表等共享边线；对齐内容本身，不只对齐外层容器。图标放在统一宽度的容器中，必要时按视觉中心微调。
- 先靠间距分组，再决定是否需要背景或分隔线。同类组件统一行高、内边距和图标文字间距；检查相邻间距是否有无意的细小差异。按既有间距刻度调整，不为个别元素不断叠加补丁。

## 色彩、层次与效果

- 区分背景、容器、选中/悬停和文字层级；通过轻微明暗差或必要的边框分层。减少同时出现的高饱和填充、渐变、发光和重阴影，把强调留给重要操作、状态或需辨认的数据。
- 检查每种效果的作用：阴影可表示浮层，边框可区分控件，颜色可表达品牌、状态或分类；重复的光效不必覆盖所有组件。允许需要的装饰和品牌风格，不机械删除渐变、圆角或阴影。
- 普通卡片可以先试背景加细边框；选中项可以先试背景和文字对比。若识别不够，再按现有体系增加强调。前景、焦点、禁用和状态在实际主题中保持可辨，不能只用颜色表达状态。

## 文字、导航与卡片

- 建立页面标题、区域标题、核心数字、正文和辅助说明的层级，结合位置、字号、字重和留白；不要所有内容都放大加粗。避免过度全大写、字间距、Emoji 和感叹号造成噪声，也不清除有产品意义的语气。
- 用清楚的业务文案替代含糊强调：变化值说明比较对象和周期，例如“较上月 +12%”；页面标题按任务决定是否展示日期或上下文，不无条件替换欢迎语。
- 导航图标尽量同风格、尺寸和线宽；当前项与普通项有明确区别。静态数量可用普通文字，未读或告警等需要提醒的状态可保留徽章；子菜单指示与真实行为一致。视觉精简不能缩小必要的点击区域。
- 数据卡片先安排标题、关键数字、变化和比较基准，再决定是否需要辅助图片；同排卡片的对应内容尽量对齐，装饰不遮挡信息。按组件层级协调圆角，相邻嵌套边界按内边距递减。

## 图表和验证

先按问题与数据选择图表：类别比较、时间趋势和精确查询可能需要不同形式；不要为了外观改掉数据含义。适当弱化网格、边框和非重点系列，类别颜色与图例一致，必要时配合标签或线型，提供可读的单位和数值。详见 [数据展示](design-data-viz.md)。

按需分轮调整布局、视觉效果、文字和组件，对照前后真实渲染，检查变化是否让主要任务更清楚。复查小字号对比、长文本、窄屏、交互状态和触控区域；静态截图不证明交互可用。

## 视觉内容与表现力

优先展示真实产品、内容或结果：例如有意义的商品图、清晰的关键数值和能回答问题的图表。营销场景可用符合产品语境的场景图、插画或更鲜明的构图；工作界面则先保证内容和操作可读，不为填满空间添加无意义的视觉物件。图片与文案互相留出空间，适配不同屏幕；生成或示例素材不能冒充真实业务事实。

图表和卡片的视觉权重由用户要回答的问题决定：需要时突出主图或关键数字，次要信息用适合数据的形式呈现。多系列颜色、徽章和辅助图形有助于辨认或比较时可以保留；不为装饰填充图表、图标或虚构数据。
