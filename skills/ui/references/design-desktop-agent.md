# 桌面与 Agent 界面

用于原生桌面外壳、分栏工作区和 Agent 会话。先确认系统、运行时、窗口类型和核心任务。窗口行为用实际桌面运行时验证，交互组件沿用现有库与原生语义。

## 工作区与控制权

- 探索与澄清用会话，精确或高频编辑提供直接控件。文档、差异与可编辑产物需要独立查看或协同修改时，用专用面板或窗口。明确当前选区、引用对象和保存目标。
- 按草稿、已受理／排队、运行、等待授权、完成、失败和停止映射真实事件。区分“已请求停止”和“已停止”，区分预览、已生成与已保存。切换窗口或会话时，草稿、附件、任务和回执按各自归属隔离，已确认的阶段结果可回看。
- 对话显示意图与结论，进度只展示用户可理解的实际阶段，工具卡按调用合并输入、影响范围、状态和结果，产物可独立查看。必要授权就地显示目标和影响，提供明确允许或拒绝。补充、取消、撤销与安全重试按底层能力提供。
- 多面板各有滚动区域，调整分栏时有拖动反馈与最小宽度。需要吸附时在边缘吸附，Esc 可取消并恢复拖动前宽度。切换对象或从详情返回时恢复阅读位置和焦点。

## 窗口、输入与滚动

- 系统窗口控制、快捷键、焦点、文本选择与原生滚动要可用。自绘标题栏隔开窗口拖拽区与按钮、输入框的命中区。透明或无边框窗口同时检查应用容器和系统窗口的物理边缘。托盘面板验证失焦、再次打开和菜单键盘导航。
- Composer 高度随输入增长，达到上限后内部滚动，保持发送和附件可见。复用平台自适应输入。在目标内核支持时可用 `field-sizing: content`。若局部收敛滚动条外观，仍需保留滚轮、触控板、键盘与文本选择。
- IME 组合输入期间，Enter 只确认候选词。先使用组合事件与平台状态。若实际内核在 `compositionend` 后再发伴生 Enter，按复现结果增加一次性守卫，可参考上游 500ms 实现，消费后清除，实测正常发送与换行。附件解析、上传、失败和移除各自有可见状态。
- 流式输出仅在用户仍贴近底部时跟随。向上阅读时保持锚点，下方有新内容则给回到底部入口。图片加载、折叠展开或代码高亮后检查位置稳定。模态浮层出现或消失时，用现有组件补偿或稳定滚动条槽位，防止背景横跳。
- 内容圆角裁切留在内层，投影放外层。定位真实裁切祖先（`overflow`、`clip-path`、绘制包含或窗口边界），按各侧阴影偏移、模糊与扩散预留余量。`clip-path: inset()` 需要圆角时显式写 `round`。改变层级值不能解除物理裁切。

## 排版与动效

- 默认收敛到三至四级字号，桌面密集界面以 12 CSS px 或等效逻辑尺寸作为常用小字下限。通过字重、对比与间距体现其余层次。深色主题按实际可读性校正字重，动态耗时、计数用等宽数字。短标题检查孤字换行，国际化控件随内容伸缩。按语言处理布局方向，代码、日志和版本号等内容保留其阅读方向。
- 内外圆角相邻时按 `max(0, 外圆角 - 内边距)` 校对。图标按视觉重心微调，装饰性分割线可优先用高 DPI 下约 0.5 CSS px 的细线，检查普通屏与缩放。用间距或细线分隔元数据，移除充当分隔符的中点和无语义左侧彩条。状态仍有可读标记。
- 拖拽跟手，吸附及时，交互过渡支持打断。结构稳定的慢加载可以使用骨架，大块与密集行的节奏分别设计，减少动效时停用连续扫光。附件重排只有在运行时支持且确有可读性收益时使用视图过渡。

## 验收

- 在当前构建的 Electron、Tauri 或原生应用中，按改动范围检查最小窗口、系统缩放、标题栏拖拽和点击、焦点、真实滚轮、中文选词、长输入、多窗口切换与流式回溯。
- 涉及阴影或透明窗口时，检查静态、实际可达的悬停与展开状态和动效中间帧。可审阅后使用上游 [clip-audit.js](https://github.com/Ludi-Herry/desktop-agent-ui/blob/5ee4fea59c279965e1a6b4b967d23d302a583dcc/scripts/clip-audit.js)估算 DOM 裁切。透明或无边框窗传 `{ viewport: true }`，局部检查以目标的父级为 `root`。复核 `cut` 与 `hidden`，矩形估算后仍需看圆角、遮罩和系统窗口的实际画面。
