# B 端设计系统

用于后台、业务工作台和密集数据操作。先确定业务对象、状态、操作频次、风险和权限，再选择页面骨架。优先复用项目现有的表格、表单、浮层与导航。

## 页面骨架

| 用户任务 | 页面结构 |
| --- | --- |
| 查找、比较或批量处理 | 页头 → 常用筛选 → 结果区 → 分页或连续加载。选择后呈现已选数量、选择范围、批量动作和清除入口。 |
| 连续处理工单或审批 | 列表与详情并排，切换对象时保持筛选、选择与位置。对象稀少或窄屏时按实际空间改用上下文面板或页面。 |
| 查看或分享对象 | 页头显示对象名、状态和操作。属性用描述列表，按业务维度分组。独立协作、书签和深链使用可寻址的详情。 |
| 新建或编辑 | 短表单默认单列、标签在上，强相关短字段可同排。长表单按业务分组，有前置依赖的多步流程用向导。 |
| 查看业务健康与待办 | 少量核心 KPI、能回答业务问题的图表、可到达的待办。统一时间口径，保留必要比较基准和单位。另读 [数据展示](design-data-viz.md)。 |
| 调整设置 | 按业务范围分组。低风险、可逆的个人偏好可即时生效，联动规则和高影响设置通过显式保存提交。 |

## 组件选型与操作

- **主操作**。页头、表格工具栏或浮层底部各自最多一个主按钮。按当前状态与最重要任务确定。审批通过与驳回等需要中立判断的并列选项保持同等视觉权重。低频次要操作可收进菜单，少量高频项留在原位。
- **选择器**。即时生效的布尔设置用开关，随表单提交的布尔值用复选框。少量互斥项平铺单选，多项或长列表用选择器，难以扫描的候选支持搜索。标签页用于相对独立的同级内容，需要来回比对的内容放在同一视野。
- **筛选与表格**。频用条件直接显示，低频条件折叠，多组复杂条件用高级筛选。已生效条件可见、可清除，刷新与返回保留筛选和分页。名称与状态文字左对齐，数量、金额及便于比较的定宽时间右对齐，勾选和单图标列居中。数值使用等宽数字。横向滚动留在表格自身，固定列在窄视口下仍要给核心内容留出空间。
- **状态徽标**。业务状态在各页使用同一语义变体和明确文字，默认低饱和浅底深字，深色主题按实际对比调整。红色保留给危险、错误或阻断。可增删的分类标签与客观状态分开。
- **表单和导入**。在字段附近提示格式和错误，提交失败保留输入并定位错误。导入分别呈现文件校验、服务端处理、成功及部分失败。按回执给出成功数量、失败明细与可用的恢复方式。

## 浮层与高风险操作

| 场景 | 形态 |
| --- | --- |
| 少量补充信息，高频查看 | 原位展开，保持表格阅读位置 |
| 轻量、低风险的原地确认 | 锚定气泡，能撤销的操作可在执行后给撤销入口 |
| 短确认、少字段聚焦输入、高风险确认 | 对话框，首尾可达，长内容在内部滚动 |
| 详情、轻编辑或高级筛选，需要保留列表上下文 | 侧边抽屉。若需同时操作列表，选择非模态抽屉或双栏 |
| 长表单、多步骤流程或独立协作 | 独立页面，返回时恢复列表上下文 |

- 先决定背景是否应保持可操作，再选组件。对话框使用组件库焦点管理，关闭后恢复合理焦点。含录入或高风险确认的浮层禁用遮罩点击关闭，保留明确退出方式。有未保存内容时保存草稿或确认丢弃。
- 不可逆删除、清空和扣款用专门的确认对话框。写清对象、数量或金额、后果和不可逆性，确认按钮明确动作，默认焦点不落在危险动作上。受理后防止重复提交，按服务实际能力显示可取消、等待回执或完成。
## 设计令牌

基础色盘供语义令牌引用，业务页面使用背景、文字、边界、品牌和状态等语义色，组件变体沿用同一映射。新界面可从 4／8px 间距刻度和 12／14／16／20px 字阶起步。装饰性分隔可用约 0.5 CSS px 的高 DPI 细线或低对比度 1px 线。交互边界与焦点保持可辨。

按项目定义窗宽档位。窄屏、缩放或长文案时优先保住内容与操作，再调视觉重心。图标按光学重心对齐，嵌套边界协调圆角，阴影留足裁切余量。

## 验收

用真实或明确标注的代表数据检查正常、首次无数据、筛选无结果、加载、失败与受限。加载中保留可用内容并标记刷新，确定结构且等待明显时才用骨架。长任务展示真实阶段，可测量时才给进度，按系统能力提供取消或后台继续。复查批量选择范围、返回恢复、脏表单退出、危险操作去重和窄屏横滚。
