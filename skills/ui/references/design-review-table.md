# 设计评审

用于明确要求的审查、视觉打磨或新表面方向评估。以当前任务、项目设计规范与对应平台参考为依据。

- **先走关键任务**。从入口走到完成或恢复，确认用户看得见当前状态、主操作和退出方式。工作台重扫描与操作，营销页面重内容表达，空状态优先交代原因与下一步。
- **看真实渲染**。用代表数据核对层级、对齐、间距、光学重心与组件状态。在支持的主题、语言、缩放和窄屏下检查文字、控件及焦点。装饰和品牌表达按任务判断，优先删除重复文案和无功能的强调。
- **实测交互与可访问性**。复查键盘顺序、模态焦点归还、字段错误、输入保留和异步结果归属。高频触发、快速中断、返回与减弱动效按改动范围验证。触控与桌面窗口问题按对应平台运行时检查。
- **输出问题及影响**。给出位置、触发条件、可见问题和修改方向，先说影响任务完成的问题。多个方案确需比较时，可用表格呈现交互、信息密度或布局差异。区分实际测量、视觉判断与缺少的证据。

方法参考 [emilkowalski/skills](https://github.com/emilkowalski/skills)、[Impeccable](https://github.com/pbakaus/impeccable)、[Vercel Agent Skills](https://github.com/vercel-labs/agent-skills)、[taste-skill](https://github.com/Leonxlnx/taste-skill) 和 [乔木设计评测](https://designskill.qiaomu.ai/)。
