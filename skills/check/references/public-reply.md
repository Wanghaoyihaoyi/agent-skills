# 对外回复与关闭

仅处理已授权的回复、修改评论和关闭动作。先从条目链接与当前项目确定平台，使用对应连接器、CLI 或 API；不把 GitHub 的命令和接口当作所有平台的约定。

1. 读取当前条目、作者、语言和状态，核对实际版本或发布证据。回复说明真实结果及对方下一步，长度与问题相称；称呼、提及语法及语气遵循平台、项目和用户要求。
2. 请求诊断材料时只要必要的非敏感信息。只有项目提供了私密支持渠道时才引用它；下一步须在对方当前故障或无障碍限制下可操作。
3. 编辑自己的评论前检查后续回复。已有人跟进时用新评论澄清，避免改写讨论前提；不编辑他人内容。结果未知先查询，避免重复发布。
4. 发出或编辑后读回目标、作者、正文和条目状态，确认实际结果。
5. 关闭遵循项目规则和有效授权。已发布、已合入未发布、重复、不计划支持分别说明依据；证据不足不能作为无效关闭。

需要润色时可使用 `write` 的公共回复模式；该技能只管措辞，不增加发送或关闭权限。
